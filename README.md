# 1 in a Million

A novel-in-progress (Book One of a planned series). Each scene lives in its own file under [sections/](sections/); [1naM_Draft.md](1naM_Draft.md) is the index into those files plus the continuity/production notes.

## Premise

A fast-acting biological event kills nearly everyone on Earth in a single night. Survival rate is roughly one in a million — around 350 people in the continental US, scattered with no concentration anywhere. Most survivors don't know they're immune until they wake up into the silence. The book follows the handful who find each other and start rebuilding some kind of shared life, without ever learning *why* they were the ones who lived.

## Repository contents

- **[sections/](sections/)** — the manuscript itself, one file per scene (`NN-dayX-slug.md`, e.g. [sections/01-day0-john.md](sections/01-day0-john.md)). This is the source of truth for prose.
- **[1naM_Draft.md](1naM_Draft.md)** — the table of contents linking to every file in `sections/`, followed by a **Continuity & Production Notes** section (canon, character bios, retcon history, and open threads). The note at the top of the file explains its current status.
- **[CLAUDE.md](CLAUDE.md)** — canon rules and continuity constraints for anyone (human or AI) doing revision work on the manuscript. Read this before editing anything.
- **[timeline.md](timeline.md)** — chronology of settled scenes, kept in sync with `sections/`.
- **power-grid-shutdown-timelines.md**, **deltaFlight84.md**, **iss-ham-radio-contact.md**, **PC-12-PRO-Brochure.pdf**, **john_lauer_persona.md** — real-world research/reference docs feeding specific subplots (grid/nuclear collapse timing, Sam's flight profile, ISS comms, real Pilatus PC-12 specs, and John's character dossier respectively). Treat them as source material to write from, not manuscript prose — and check them before inventing mechanical/technical details a source already covers.
